## Assignment Description
20 Python programs that practise **for loops**, **while loops** and **functions**,
moving from simple number problems to complete menu-driven applications
(ATM, bank account, shopping cart, student registration system).

## Setup / How to Run
1. Install **Python 3.8 or newer** (`python --version` to check).
2. Clone the repository:
   ```bash
   git clone https://github.com/<your-username>/super30-python-loops-functions-assignment.git
   cd super30-python-loops-functions-assignment
   ```
3. Run any program:
   ```bash
   python 01_number_analyzer.py
   ```
   (On some systems use `python3` instead of `python`.)

No external libraries are required. Only Python's built-in `random` module is used (Q12).
